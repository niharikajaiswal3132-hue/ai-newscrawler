📌 What is NewsCrawler?
A real-time AI-powered news dashboard that aggregates headlines from 6 major sources and generates instant AI summaries using LLaMA 3.3 70B.
✨ Features
📡 Real-time news from 6 sources
🤖 AI summaries via Groq LLaMA 3.3 70B
📂 Filter by source & category
🗂️ Sub-category filtering within each news channel
🔗 Direct article links — Read Full Article
🌗 Dark/Light theme toggle
🔄 Auto-refresh dashboard
📅 Sort by Latest → Oldest & Oldest → Latest
📱 Mobile responsive & live deployed
